Crimson Harbor is an original open-world crime game that runs in the browser: steal cars, outrun the police across five wanted levels, and play six story missions through a living harbor city. Vanilla JS + Canvas 2D — no build step, no network.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
